# Дашборды в Yandex DataLens: аналитика "Клуба по интересам"

## Описание проекта

В этом проекте созданы интерактивные дашборды в Yandex DataLens для анализа активности участников клуба по интересам.

Дашборды помогают ответить на вопросы:

- какие хобби приносят наибольшую выручку;
- какие мастер-классы получают высокие и низкие оценки;
- как распределяются пользователи по возрасту и полу;
- есть ли связь между длительностью и стоимостью мастер-классов;
- какие категории стоимости выбирают разные возрастные группы;
- как меняется средняя оценка в разрезе хобби и пола.

## Стек

- Yandex DataLens
- MS Excel
- BI-визуализация
- вычисляемые поля
- дашборды
- селекторы и фильтры

## Этапы работы

### 1. Загрузка данных и создание датасета

- создано подключение к файлу `Dataset.xlsx`;
- создан датасет «online_masterclasses_dataset»;
- проверены типы столбцов;
- добавлены агрегации:
  - средняя оценка;
  - сумма стоимости.

### 2. Базовые визуализации

Созданы чарты:

1. Таблица «Пользователи и их траты».
2. Столбчатая диаграмма «Средняя оценка по хобби».
3. Гистограмма «Распределение по возрасту».
4. Круговая диаграмма «Доля выручки по хобби».
5. Точечная диаграмма «Длительность vs стоимость».

### 3. Первый дашборд

Создан дашборд «Dashboard 1».

Состав:

- таблица пользователей снизу на всю ширину;
- гистограмма и круговая диаграмма в верхнем ряду;
- столбчатая и точечная диаграммы во втором ряду;
- текстовый виджет с пояснением.

### 4. Селекторы

Добавлены интерактивные фильтры:

- селектор по полу, одиночный выбор;
- селектор по хобби, множественный выбор.

Это позволяет пользователю дашборда быстро смотреть срезы по отдельным группам.

### 5. Вычисляемые поля

Созданы новые аналитические поля:

| Поле | Описание |
|---|---|
| Возрастная группа | сегментация по возрасту: 18–29, 30–44, 45–59, 60+ |
| Категория стоимости | бюджетный, средний, дорогой |
| Флаг высокой оценки | masterclass_rate >= 8 |
| Стоимость минуты | masterclass_cost / duration_min |
| Полное имя | CONCAT(last_name, ' ', first_name) |

### 6. Продвинутые визуализации

Созданы чарты:

1. Столбчатая диаграмма «Стоимость минуты по хобби».
2. Сводная таблица «Средняя оценка по хобби и полу».
3. Сводная таблица «Популярность категорий по возрастам».
4. Комбинированный график «Количество и оценка по хобби».
5. Точечная диаграмма «Разброс оценок по хобби».

### 7. Продвинутый дашборд

Создан дашборд «Dashboard 2».

Состав:

- верхний ряд: две сводные таблицы;
- средний ряд: комбинированный график и столбчатая диаграмма;
- нижний ряд: точечная диаграмма на всю ширину;
- селекторы по хобби, полу и возрастной группе;
- текстовое пояснение.

Добавлен параметр для фильтрации по диапазону значений, например:

- «младше ___ лет».

С помощью параметра можно анализировать отдельные возрастные группы.

## Аналитические вопросы, которые решает дашборд

1. Какие хобби наиболее прибыльны?
2. Какие хобби имеют высокую среднюю оценку?
3. Есть ли хобби с большим количеством участников, но низкой оценкой?
4. Как возрастные группы选择不同的 категории стоимости?
5. Отличаются ли оценки по хобби в разрезе пола?
6. Как соотносятся длительность и стоимость мастер-классов?
7. Есть ли выбросы по оценкам или стоимости?

## Результаты

В результате работы созданы два дашборда:

- базовый дашборд для общего обзора активности клуба;
- продвинутый дашборд для сравнительной и сегментной аналитики.

Дашборды позволяют руководителю клуба быстро оценивать:

- выручку по направлениям;
- популярность хобби;
- удовлетворенность участников;
- возрастные и гендерные различия;
- эффективность мастер-классов по стоимости минуты.
