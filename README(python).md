# Анализ рынка недвижимости Москвы и Московской области

## Описание проекта

В этом проекте выполнен исследовательский анализ датасета объявлений жилой недвижимости Москвы и Московской области.

Данные представляют собой объявления о продаже.

## Цель

Ответить на вопросы:

1. Насколько различается рынок Москвы и Московской области?
2. Какие сегменты рынка являются наиболее массовыми?
3. Удобнее ли сравнивать объекты по общей цене или по цене за квадратный метр?
4. Связаны ли цена за квадратный метр, площадь, число комнат, тип ремонта и близость к метро?
5. Какие сегменты выглядят наиболее дорогими?
6. Какие выводы нельзя делать только на основании данного датасета?

## Стек

## Данные

Использован датасет `moscow_housing`.

Основные характеристики:

- 22 676 строк;
- 12 исходных столбцов;
- регионы: Москва и Московская область;
- типы рынка: вторичный рынок и новостройки.

Основные поля:

| Поле  | Описание |
|---|---|
| Price | цена объекта |
| Apartment type | тип рынка |
| Metro station | ближайшая станция метро |
| Minutes to metro | время до метро, минуты |
| Region | Москва / Московская область |
| Number of rooms | число комнат |
| Area | общая площадь, кв.м. |
| Living area | жилая площадь, кв.м. |
| Kitchen area | площадь кухни, кв.м. |
| Floor | этаж |
| Number of floors | этажность дома |
| Renovation | тип ремонта |

## Ход работы

### 1. Экспресс-аудит данных

Были проверены:

- количество строк и столбцов;
- типы данных;
- пропуски;
- уникальные значения;
- полностью совпадающие строки;
- некорректные значения.

Проверены условия:

```text
Price <= 0
Area <= 0
Living area > Area
Kitchen area > Area
Floor < 1
Number of floors < 1
Floor > Number of floors
Minutes to metro < 0
Number of rooms < 0

Отдельно проанализировано значение "Number of rooms = 0".

Такие записи не удалялись автоматически, потому что их площади заметно меньше площадей обычных 1–2-комнатных квартир. В рамках данного датасета их разумно интерпретировать как студийный сегмент.

### 2. Создание аналитических признаков

Были добавлены новые поля:

| Признак  | Описание |
| Price per sqm | цена за квадратный метр |
| Living share | доля жилой площади |
| Floor valid | корректность соотношения этажа и этажности |
| Floor share | относительный этаж для корректных записей |
| Metro group | категория доступности метро |

Категории метро:

- до 5 минут;
- 5–10 минут;
- 10–20 минут;
- более 20 минут.

### 3. Сравнение Москвы и Московской области

Для каждого региона рассчитаны:

- количество объявлений;
- медианная цена;
- медианная площадь;
- медианная цена за квадратный метр;
- медианное время до метро.

Использована медиана, потому что она менее чувствительна к выбросам, чем среднее значение.

### 4. Анализ структуры рынка

Для каждого сегмента рассчитаны:

- количество объявлений;
- медианная цена;
- медианная цена за квадратный метр;
- медианная площадь.

В анализ оставлены только сегменты с количеством объявлений не менее 30, чтобы повысить устойчивость выводов.

### 5. Исследование факторов цены

Проанализированы зависимости медианной цены за квадратный метр от:

- типа ремонта;
- доступности метро;
- числа комнат.

### 6. Визуальный аналитический лист

Создана фигура из четырех графиков:

1. распределение цены за квадратный метр;
2. сравнение цены за квадратный метр по регионам;
3. зависимость цены от площади;
4. медианная цена за квадратный метр по типу ремонта и региону.

Для визуализации использовалось ограничение по 99-му процентилю, чтобы редкие экстремальные значения не искажали основной диапазон графиков.

### 7. Подборка для гипотетического покупателя

Условия покупателя:

- квартира в Москве;
- 2 комнаты;
- площадь от 50 до 80 кв.м.;
- не более 15 минут до метро;
- корректное соотношение этажа и этажности.

Для выборки рассчитаны:

- количество вариантов;
- медианная цена;
- медианная цена за квадратный метр;
- 25-й и 75-й процентили общей цены.

Также найдены 5 самых дешевых объектов по цене за квадратный метр.

### Основные выводы

1. Рынки Москвы и Московской области существенно различаются.
2. Для сравнения объектов цена за квадратный метр часто информативнее общей цены.
3. Наиболее массовые сегменты связаны с вторичным рынком и компактными квартирами.
4. Дорогие массовые сегменты характерны прежде всего для Москвы.
5. Различия по числу комнат, ремонту и доступности метро позволяют выделять ценовые категории, но требуют осторожной интерпретации.
6. Данные представляют собой объявления, а не сделки, поэтому выводы относятся к ценам предложения.
