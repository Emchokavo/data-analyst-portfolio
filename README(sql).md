# SQL-аналитика базы данных «Клуб по интересам»

## Описание проекта

Проект выполнен на основе учебной реляционной базы данных клуба по интересам.

«Клуб по интересам» объединяет людей с общими увлечениями: танцы, спорт, музыка, аналитика, кулинария и другие направления. База данных содержит информацию об участниках, хобби, мероприятиях, посещениях, достижениях и онлайн-мастер-классах.

Цель проекта — научиться переводить бизнес-вопросы в SQL-логику, получать аналитические выборки и рассчитывать метрики для поддержки управленческих решений.

## Стек

- SQL
- SQLite / DBeaver
- реляционные базы данных

## Структура базы данных

Основные таблицы:

| Таблица | Описание |
|---|---|
| users | участники клуба: ID, ФИО, возраст, пол, дата регистрации |
| hobbies | справочник хобби |
| user_hobbies | связь пользователей и хобби |
| events | мероприятия клуба |
| event_attendance | посещения мероприятий пользователями |
| achievements | достижения участников |
| online_masterclasses | онлайн-мастер-классы: длительность, стоимость, оценка |

Таблицы связаны через внешние ключи, что позволяет анализировать пользователей, их интересы, активность и расходы.

## Задачи проекта

### 1. Знакомство с таблицами

- изучение структуры таблицы `users`;
- выборка первых пользователей.

### 2. Фильтрация и сортировка

- выборка пользователей младше 40 лет;
- топ-5 самых дорогих мастер-классов;
- мастер-классы с оценкой от 9 до 10.

### 3. Агрегатные функции

Расчитаны общие метрики:

- количество мастер-классов;
- общая выручка;
- средняя стоимость;
- средняя оценка;
- минимальная и максимальная длительность;
- количество пользователей с указанными хобби.

### 4. GROUP BY

Выполнена группировка:

- по хобби: средняя стоимость, средняя оценка, количество мастер-классов;
- по пользователям: количество мастер-классов и общая сумма затрат.

### 5. JOIN

Использованы:

- `INNER JOIN` для связи пользователей и их хобби;
- `LEFT JOIN` для поиска пользователей без достижений;
- многотабличные JOIN для получения информации о пользователях, хобби, стоимости и оценках мастер-классов.

### 6. Подзапросы и CTE

С помощью CTE решена задача:

- найти пользователей, чья суммарная стоимость мастер-классов выше средней суммы по всем пользователям.

### 7. Оконные функции

Использована функция `RANK` для ранжирования пользователей по общей потраченной сумме.

### 8. Статистические расчеты

Выполнены расчеты:

- медианная стоимость мастер-класса;
- дисперсия длительности;
- стандартное отклонение длительности;
- поиск выбросов стоимости по правилу IQR.

### Примеры аналитических вопросов

Проект отвечает на вопросы:

1.Какие мастер-классы приносят наибольшую выручку?
2.Какие хобби имеют самую высокую среднюю оценку?
3.Какие пользователи тратят больше всего?
4.Есть ли пользователи без достижений?
5.Посещают ли пользователи мастер-классы вне своих основных хобби?
6.Какие мастер-классы являются статистическими выбросами по стоимости?
7.Какова медианная стоимость мастер-класса?
8.Насколько сильно различается длительность мастер-классов?
