# Портфолио аналитика данных

Репозиторий содержит учебно-практические проекты начинающего аналитика данных по SQL, Python и Yandex DataLens.

## Проекты

### 1. Анализ рынка недвижимости Москвы и Московской области

**Стек:** Python, pandas, numpy, matplotlib, seaborn

Выполнен EDA датасета из 22 676 объявлений: проверка качества данных, создание признаков, сравнение регионов, анализ сегментов, визуализация и подготовка выводов с учетом ограничений данных.

### 2. SQL-аналитика базы «Клуб по интересам»

**Стек:** SQL, SQLite / DBeaver

Написаны запросы с JOIN, GROUP BY, агрегациями, подзапросами, CTE и оконными функциями. Рассчитаны выручка, средние оценки, топ пользователей, медиана, дисперсия и выбросы по IQR.

### 3. Дашборды в Yandex DataLens

**Стек:** Yandex DataLens

Созданы датасет, вычисляемые поля, интерактивные чарты и дашборды для анализа активности участников, стоимости мастер-классов, оценок и выручки по хобби.

## Навыки

SQL, Python, pandas, numpy, matplotlib, seaborn, Yandex DataLens, Excel, EDA, визуализация данных, очистка данных, агрегация, JOIN, CTE, оконные функции, дашборды.
